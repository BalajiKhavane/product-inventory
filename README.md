# 📦 Product Inventory Management System

A simple CRUD web application built with PHP, MySQL, and Bootstrap.

## 🛠️ Built With
- **Frontend** — HTML, CSS, Bootstrap 5
- **Backend** — PHP
- **Database** — MySQL

## ✨ Features
- Add new products
- View all products
- Edit existing products
- Delete products

## 📁 Project Structure

    product-inventory/
    │
    ├── index.php           → View all products
    ├── add.php             → Add new product
    ├── edit.php            → Edit product
    ├── delete.php          → Delete product
    │
    ├── css/
    │   └── style.css       → Custom styles
    │
    └── includes/
        └── db.php          → Database connection
